Secure Key Establishment (SKE) - is provided if each party in the protocol is able to determine the identity of the other parties - unlike entity authentication it is not necessary to determine whether the other parties have actually participated in the protocol.

Implicit Key Authentication (IKA) - is the process where one party is assured that only specifically identified parties may gain access to a particular secret key.

Key Confirmation - is the property were one party is assured that a second, possibly unidentified, party actually has possession of a particular secret key.

Explicit Key Authentication (EKA) - is the property where both implicit key authentication and key confirmation hold.

Authenticated Key Establishment Protocol (AKEP) - is a key establishment protocol which provies explicit key authentication.
